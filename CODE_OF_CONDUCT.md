# Code of Conduct

## The short version

Be decent. Assume the other person is acting in good faith, and give them reason to
assume the same of you.

This is a small language-learning project. Most interactions here will be someone
reporting that an exam answer looks wrong, or that the timer misbehaved on their phone.
Those are useful contributions and deserve a straight, respectful answer.

## Expected behaviour

- Critique the work, not the person. "This answer key is ambiguous because the text
  supports both b and c" is useful. "Whoever wrote this doesn't know German" is not.
- Accept that people are learning. Someone whose German or whose JavaScript is weaker
  than yours is exactly who this project is for.
- Be specific. A bug report with the exam number, the item and what you expected is worth
  more than a strongly-worded one.
- Respect a decision once it is made and explained, even if you disagree with it.

## Unacceptable behaviour

- Harassment, intimidation, or sustained disruption of discussion.
- Personal attacks, or comments demeaning someone's nationality, language ability, race,
  gender, sexuality, disability, religion, age or appearance.
- Publishing someone's private information.
- Unwelcome sexual attention or imagery.
- Deliberately derailing issues or reviews.

## Scope

This applies to issues, pull requests, commit messages, code comments and any other
project space, plus situations where someone is representing the project publicly.

## Reporting

Report a problem by opening a
[private security advisory](https://github.com/prangonsafayet/pruefungstrainer-deutsch/security/advisories/new),
which is the only private channel this repository has. Include what happened, where, and
links if you have them.

Reports are read by the maintainer, who is also the only person able to act on them —
this is a one-person project, so there is no separate committee and no pretence of one.
Your report will be kept as private as GitHub allows.

## Enforcement

Depending on severity, the response will be one of: a private word, a public correction,
editing or removing the offending content, or blocking the account from the repository.
Anything involving harassment of an individual goes straight to the last of those.

If you think a decision was wrong, say so in the same channel you reported through. You
will get a reasoned answer, not necessarily a different one.

## Attribution

The structure follows the [Contributor Covenant](https://www.contributor-covenant.org)
in spirit. The wording is deliberately this project's own, so that it says what will
actually happen here rather than describing a governance process that does not exist.
